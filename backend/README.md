# Backend

FastAPI service that owns the AeroAPI/OpenSky integration, caching, and the Postgres schema. See
[`../docs/ARCHITECTURE.md`](../docs/ARCHITECTURE.md) for the design and [`../docs/API.md`](../docs/API.md)
for the endpoint contract.

## Setup

```bash
# From the repo root: start Postgres and copy the env template if you haven't already
docker compose up -d db
cp ../.env.example ../.env   # then fill in AEROAPI_KEY / OPENSKY_CLIENT_ID / OPENSKY_CLIENT_SECRET

cd backend
pip install -e ".[dev]"
alembic upgrade head
uvicorn app.main:app --reload --port 8000
```

The `.env` file lives at the repo root (`../.env` from here) and is loaded via `pydantic-settings`
(`app/config.py`) — both the backend and `docker-compose.yml` read from it.

API docs (Swagger UI) once running: http://localhost:8000/docs

## Running without spending AeroAPI credit

Set `FIXTURE_MODE=true` in `.env` (or export it) to swap both external clients for canned data (see
`app/clients/fixtures.py`) — try `GET /api/flights/search?ident=FIX100&date=2026-09-12` for an "airborne"
demo flight, or `FIX200` for a "landed" one.

## Tests

```bash
pytest                    # everything
pytest tests/unit         # fast, no DB, all clients mocked
pytest tests/integration  # needs the docker-compose Postgres running
```

See [`../docs/TESTING.md`](../docs/TESTING.md) for the full test strategy.

## Database migrations

```bash
alembic revision --autogenerate -m "describe the change"
alembic upgrade head
```

Always review an autogenerated migration before committing it — Alembic's diffing isn't perfect,
especially around enum types and index changes.

## Layout

```
app/
  clients/    raw AeroAPI/OpenSky HTTP wrappers (+ fixtures.py for FIXTURE_MODE)
  services/   business logic — caching decisions, icao24 resolution, aggregation
  routers/    thin FastAPI route handlers
  db/         SQLAlchemy models + session management
  schemas/    Pydantic request/response DTOs
  core/       cache TTL helpers, dev-time AeroAPI call-budget guard
tests/
  unit/         mocked clients, no DB
  integration/  FastAPI TestClient + real test DB, HTTP still mocked
```

See the root [`CLAUDE.md`](../CLAUDE.md) for the two things you need to understand before changing
anything in `services/` (the icao24 linking problem and the AeroAPI cost-control rule).
